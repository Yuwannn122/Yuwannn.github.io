# Yuwannn.github.JobFish
# 🐟 JobFish — 你的求职数据指挥舱

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://opensource.org/licenses/MIT)
[![Made with Vanilla JS](https://img.shields.io/badge/Made%20with-Vanilla%20JS-f0db4f.svg)](https://developer.mozilla.org/en-US/docs/Web/JavaScript)

> 专为求职者打造的个人数据追踪仪表盘。  
> 全流程追踪投递状态，用漏斗图和决策分析看清每一步求职转化。

---

## ✨ 核心功能

- **全流程状态追踪** — 从“已投递”到“沟通中”“面试中”直至“已入职”，精细管理每个岗位进度。  
- **漏斗转化分析** — 一眼看出简历投递 → 面试 → Offer 的转化瓶颈，定位该优化的环节。  
- **主动 vs 被动决策洞察** — 清晰区分“你拒绝公司”与“公司拒绝你”，了解自己的底线与市场反馈。  
- **渠道效果对比** — Boss 直聘、官网、猎头…哪个渠道转化率最高？数据告诉你答案。  
- **本地存储，隐私安全** — 所有数据保存在浏览器 localStorage，不上传任何服务器，完全由你掌控。

## 🚀 如何使用

### 方式一：在线体验（推荐）
直接访问 GitHub Pages 链接：  
👉 **[ https://yuwannn122.github.io/Yuwannn.github.io/) ]**

### 方式二：本地运行
1. 克隆仓库  
   `git clone https://github.com/Yuwannn122/jobfish.git`
2. 用浏览器打开 `index.html` 即可
3. 点击“新增记录”开始录入你的求职数据

---

## 📝 使用说明

1. 点击左上角 **+ 新增投递**，填写公司、岗位、渠道、薪资等信息。  
2. 随着求职进展，随时**更新状态**（如从“沟通中”改为“面试中”）。  
3. 顶部的概览卡片和下方图表会自动刷新，反映最新的求职全貌。
4. 支持批量导入&导出 xlsx/CSV格式求职数据

## 💡 项目背景与洞察

在求职过程中，我曾同时投递 30+ 岗位，很快陷入“信息混乱”：  
- 记不清每家公司的进度，遗忘跟进时间  
- 凭感觉猜测哪个渠道效率高，缺乏数据支撑  
- 不清楚自己是在简历关被卡，还是面试环节有问题  

于是我运用数据分析思维，为自己量身打造了 **JobFish**。使用它之后，我真实发现了自己的面试转化率短板，并据此调整了投递策略。  
这个项目不仅是我的**数据分析能力证明**，更是一个真正在求职中帮到我自己的实用工具。
